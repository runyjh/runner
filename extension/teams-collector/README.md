# 러너 팀즈 수집기 (크롬 확장)

크롬에 열어 둔 팀즈 웹(teams.microsoft.com / teams.cloud.microsoft)의 메시지 중
관리자 화면에서 정한 **키워드·볼 채널**에 맞는 것을 러너 올인원 서버로 보냅니다.
러너 올인원 관리자 → 대시보드 → **팀즈 소식** 카드에 보입니다.

## 설치 (팀즈를 볼 PC에서 한 번)
1. `runner-teams-collector.zip` 압축 풀기 (폴더는 지우지 않기)
2. 크롬 `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → `teams-collector` 폴더
3. 관리자 화면 → 대시보드 → 팀즈 소식 → 전체 · 설정 → 설정 · 수집기 → **연결 코드 만들기** → 복사
4. 크롬 퍼즐 아이콘 → 러너 팀즈 수집기 → 코드 붙여 넣기 → **연결**
5. 팀즈 웹에서 볼 채널을 탭마다 하나씩 열어 두기
6. 크롬 **설정 → 성능 → 항상 활성 상태로 유지할 사이트**에 `teams.microsoft.com`, `teams.cloud.microsoft` 추가

## 아이콘 배지
- 없음: 정상 · `!` 빨강: 서버 오류 · `!` 노랑: 연결 전 · `끔`: 관리자가 수집을 꺼 둠

## 업데이트
새 zip 을 같은 폴더에 덮어쓴 뒤 `chrome://extensions` 에서 이 확장의 ↻(새로고침)을 누릅니다. 연결 코드는 그대로 남습니다.

## 팀즈 화면이 바뀌어 못 읽을 때
확장 아이콘 → '화면에서 찾은 메시지'가 0개면 `content.js` 맨 위 `SEL` 의 선택자를 고칩니다.
