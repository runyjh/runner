# 러너 올인원

택배 영업점 러너의 기사 관리·배차·정산 올인원 프로그램입니다.

| 무엇 | 어디에 |
| --- | --- |
| 프로그램 코드 (화면, 서버) | **이 GitHub 저장소** |
| 백엔드 데이터 (기사 정보, 로그인 기록) | 구글 드라이브의 `러너 올인원 DB` 시트 |
| 기사 서류 사진 | 구글 드라이브의 `기사 서류` 폴더 |
| 암호화 키 | Apps Script 스크립트 속성 (저장소에 없음) |

저장소의 `main` 브랜치에 코드가 올라오면 GitHub Actions가 **문법 검사 → Apps Script에 올리기 → 웹앱 새 버전 배포**를 자동으로 합니다. 기사용 앱 주소(URL)는 바뀌지 않습니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `src/Code.gs` | 서버 코드 (구글 시트·드라이브 입출력, 시트 직접 수정 처리, 암호화, 로그인) |
| `src/Index.html` | 기사용 화면 (로그인, 회원가입, 비밀번호 찾기·변경) |
| `src/Admin.html` | 관리자 화면 (기사 정보관리, 스케줄관리, 노선관리, 업무스케줄, 배번호 관리·서류 4종 인쇄 양식) — 웹앱 주소 뒤에 `?page=admin` |
| `src/appsscript.json` | Apps Script 설정 (서울 시간대, 웹앱 공개 범위) |
| `scripts/check.js` | 배포 전 문법 검사 |
| `.github/workflows/deploy.yml` | 자동 배포 설정 |

## 처음 한 번만 하는 설정

### 1. Apps Script 프로젝트 만들기

1. 러너 업무용 구글 계정으로 [script.google.com](https://script.google.com) → **새 프로젝트** → 이름을 `러너 올인원`으로 바꿉니다. 코드는 붙여넣지 않습니다.
2. 왼쪽 **⚙ 프로젝트 설정** → **스크립트 ID**를 복사해 둡니다. → `SCRIPT_ID`
3. [script.google.com/home/usersettings](https://script.google.com/home/usersettings) 에서 **Google Apps Script API** 를 **사용**으로 바꿉니다. (자동 배포에 필요)

### 2. 자동 배포용 인증 정보 만들기

PC에 [Node.js](https://nodejs.org) (LTS)를 설치한 뒤, 터미널(윈도우는 명령 프롬프트)에서 실행합니다.

```
npx @google/clasp@2.4.2 login
```

브라우저가 열리면 1번과 **같은 구글 계정**으로 로그인하고 허용합니다. 그러면 아래 파일이 생깁니다.

- 윈도우: `C:\Users\사용자이름\.clasprc.json`
- 맥: `/Users/사용자이름/.clasprc.json`

이 파일을 메모장으로 열어 **내용 전체**를 복사해 둡니다. → `CLASPRC_JSON`
이 내용은 구글 계정 열쇠와 같으니 다른 곳에 붙여넣거나 공유하지 마세요.

> PC에 설치하기 어렵다면 GitHub 저장소의 **Code → Codespaces → Create codespace** 로 연 터미널에서
> `npx @google/clasp@2.4.2 login --no-localhost` 를 실행해도 됩니다.

### 3. GitHub Secrets 등록

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서 등록합니다.

| 이름 | 값 |
| --- | --- |
| `SCRIPT_ID` | 1번에서 복사한 스크립트 ID |
| `CLASPRC_JSON` | 2번에서 복사한 `.clasprc.json` 내용 전체 |
| `DEPLOYMENT_ID` | 6번에서 등록 (지금은 비워 둠) |

### 4. 첫 코드 올리기

저장소 **Actions → Apps Script 배포 → Run workflow** 를 누릅니다. 1~2분 뒤 초록색 체크가 뜨면 성공입니다. (DEPLOYMENT_ID 가 없다는 노란 경고는 정상입니다.)
Apps Script 편집기를 새로고침하면 `Code.gs`, `Index.html` 이 들어와 있습니다.

### 5. setup 실행 (DB 만들기)

1. 편집기에서 함수 선택 칸을 **`setup`** 으로 바꾸고 **▶ 실행**합니다.
2. **권한 검토** → 계정 선택 → "확인하지 않은 앱" 경고에서 **고급 → 러너 올인원(으)로 이동 → 허용**. 본인이 만든 스크립트라 나오는 정상 경고입니다.
3. 로그에 `설정 완료. DB: https://...` 가 나오면 드라이브에 `러너 올인원 데이터` 폴더, `러너 올인원 DB` 시트, `기사 서류` 폴더가 생긴 것입니다.

### 6. 웹앱 첫 배포

1. 편집기 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**
2. 다음 사용자 인증 정보로 실행: **나** / 액세스 권한: **모든 사용자** → **배포**
3. 나오는 **웹 앱 URL** 이 기사용 앱 주소입니다.
4. 같은 화면의 **배포 ID** 를 복사해 GitHub Secret `DEPLOYMENT_ID` 로 등록합니다.

이제부터는 코드가 바뀔 때마다 이 배포가 자동으로 새 버전이 됩니다.

## 코드를 고칠 때

1. GitHub에서 `src/` 의 파일을 고치고 `main` 에 커밋합니다. (웹에서 연필 아이콘으로 바로 고쳐도 됩니다)
2. **Actions** 탭에서 진행을 확인합니다. 문법 오류가 있으면 빨간 X 로 멈추고 배포하지 않습니다.
3. 초록 체크가 뜨면 기사용 앱에 반영된 것입니다. 휴대폰에서 새로고침해 확인하세요.
4. 릴리스 안내에 "setup 다시 실행"이 있으면 편집기에서 `setup` 을 한 번 실행합니다. 기존 데이터는 지워지지 않습니다.

**Apps Script 편집기에서 코드를 직접 고치지 마세요.** 다음 자동 배포 때 저장소 내용으로 덮어써집니다.

## 관리자 화면

주소: **웹앱 URL 뒤에 `?page=admin`** 을 붙입니다.
예) `https://script.google.com/macros/s/…/exec?page=admin`

### 첫 관리자 만들기

1. 새 코드가 배포된 뒤 편집기에서 **`setup`** 을 한 번 실행합니다. DB 시트에 `admins`(관리자 계정), `admin_log`(관리자 작업 기록) 탭이 생깁니다.
2. `admins` 탭 2행에 **아이디**, **이름**, **비밀번호 재설정**(영문+숫자 8자 이상)을 입력합니다.
3. 잠시 뒤 관리자ID·생성일시가 채워지고 비밀번호 칸이 비워지면 완료입니다. 위 주소로 로그인합니다.

관리자를 더 추가할 때도 같은 방법입니다. 관리자를 막으려면 **상태**를 `정지` 로 바꿉니다.

### 기사 정보관리에서 할 수 있는 것

| 기능 | 방법 |
| --- | --- |
| 상태별 보기 | 위쪽 탭(전체/승인대기/승인/반려/정지). 승인대기가 있으면 그 탭이 먼저 열림 |
| 기사구분별 보기 | 둘째 줄 탭(고정/백업/품앗이/외부용차). 구분이 비어 있는 기사는 **구분 미지정** 탭 |
| 검색 | 이름, 기사코드, 아이디, 연락처, 차량, 캠프, 라우트 |
| 새 기사 등록 | 오른쪽 위 **+ 새 기사 등록** → 이름과 기사구분만 필수, 나머지는 나중에 채워도 됨. 바로 **승인** 상태로 등록 |
| 배정 캠프 · 라우트 | 상세(또는 새 기사 등록)의 **배정 캠프 · 라우트** 에서 노선관리에 등록된 캠프를 고르고, 그 캠프의 라우트를 눌러 여러 개 선택. 일부 회전만 맡으면 회전(D1·D2·F3) 체크 해제. 백업 기사는 **백업**, 용차는 **용차**. 저장하면 기사의 소속캠프·기본노선이 되어 스케줄관리(미입차 계산, 빈칸 자동 채우기)에 그대로 쓰입니다 |
| 기사구분·기사코드 | 상세 맨 위에서 고정/백업/품앗이/외부용차 버튼, 기사코드 입력. **자동**을 누르면 같은 구분의 가장 큰 번호 다음 번호를 제안 (예: B007 → B008) |
| 가입 승인·반려·정지 | 기사 줄을 눌러 상세 → 상태 버튼 → 저장 |
| 정보 수정 | 상세에서 고친 뒤 저장. 바뀐 칸은 주황색으로 표시 |
| 주민번호·면허번호·계좌번호 | **전체 보기**(30초 뒤 다시 가림), **변경**(새 번호 전체 입력) |
| 서류 확인 | 서류 칸의 **보기** → 화면에서 바로 사진/PDF 확인 |
| 임시 비밀번호 | 상세 맨 아래 **임시 비밀번호 지정** → 기사는 다음 로그인 때 직접 변경 |
| 선택한 기사 삭제 | 목록 왼쪽 체크박스로 여러 명 선택 (맨 위 체크박스 = 지금 보이는 기사 모두) → **선택한 기사 삭제** → `3명 삭제` 처럼 표시된 문구를 그대로 입력해야 삭제됨. 처리 내용은 한 명 삭제와 같음 |
| 기사 삭제 | 상세 맨 아래 **기사 삭제** → 기사 이름을 그대로 입력해야 삭제됨. 앱 로그인은 바로 끊기고, 가입 서류 폴더는 드라이브 휴지통으로 (30일 안 복구 가능). 배번호 신청서 등 기록은 남음. 잠시 쉬는 기사는 삭제 대신 **정지** 권장 |

- 기사코드는 기사마다 겹칠 수 없습니다 (영문은 자동 대문자).
- 외부용차처럼 앱을 쓰지 않는 기사는 쿠팡플렉스 아이디 없이 등록할 수 있습니다 (목록에 **앱 미사용** 표시). 나중에 앱을 쓰게 되면 아이디를 넣고 **임시 비밀번호 지정**을 하면 됩니다.
- 등록할 때 쿠팡플렉스 아이디와 **앱 임시 비밀번호**를 같이 넣으면, 기사님은 그 비밀번호로 바로 로그인한 뒤 새 비밀번호를 정합니다.
- 상세를 연 뒤 시트나 다른 관리자가 같은 기사를 먼저 고쳤다면, 저장할 때 "새로고침 후 다시 수정해 주세요"라고 막습니다. 덮어쓰기를 방지합니다.
- 개인정보 **전체 보기**, **서류 보기**, **정보 수정**, **임시 비밀번호 지정**, **기사 등록·삭제**는 `admin_log` 탭에 누가 언제 했는지 자동으로 기록됩니다.
- 시트에서 직접 고치는 방법도 그대로 쓸 수 있습니다. 관리자 화면에서 **새로고침**을 누르면 시트 내용이 반영됩니다.

### 업무스케줄 (관리자 전용 날짜별 메모)

관리자 화면 왼쪽 메뉴 **업무스케줄**을 누릅니다. 처음 쓰기 전에 편집기에서 `setup` 을 한 번 실행하면 DB 시트에 `work_memo` 탭이 생깁니다.

| 기능 | 방법 |
| --- | --- |
| 날짜 고르기 | 달력에서 날짜를 누름. **‹ ›** 로 달 이동, **오늘** 로 이번 달 |
| 메모 추가 | 오른쪽에 시간(선택)과 내용을 쓰고 **추가** (Ctrl+Enter). 날짜 칸을 바꾸면 다른 날짜에 바로 추가 |
| 완료 | 메모 앞 체크박스. 달력에는 줄이 그어져 보임 |
| 수정·날짜 옮기기 | **수정** → 날짜·시간·내용 변경 → 저장 |
| 삭제 | **삭제** |
| 밀린 일 확인 | 지난 날짜에 완료 안 된 메모가 있으면 위쪽 빨간 줄에 건수가 나오고, **보기**를 누르면 가장 오래된 날짜로 이동 |

`work_memo` 시트에서 직접 줄을 추가·수정·삭제해도 됩니다. 날짜와 내용만 쓰면 메모ID와 작성일시가 자동으로 채워지고, 날짜는 `2026.11.3` 처럼 써도 `2026-11-03` 으로 맞춰집니다. 완료 칸에는 `Y` 를 넣습니다. 관리자 화면에서 **새로고침**을 누르면 반영됩니다.

### 배번호 관리 ('배' 번호판 허가 신청)

처음 쓰기 전에 편집기에서 `setup` 을 한 번 실행하면 DB 시트에 `bib_applications`(신청서), `company`(회사 고정 정보) 탭이 생기고, `drivers` 에 **차량번호** 열이 추가됩니다.

1. **회사 정보 확인**: 배번호 관리 → **회사 정보**. 택배서비스사업자, 영업점, 대표자, 관할법원 등이 서류에 그대로 들어갑니다. (`company` 탭에서도 수정 가능)
2. **새 신청서**: **새 신청서** → 기사 선택. 신청일·계약기간(오늘부터 1년)·관리 방법(자동 증명)이 기본으로 채워지고, 같은 기사의 지난 신청서가 있으면 연료·형태·경력도 가져옵니다.
3. **빈 항목 채우기**: 상세 맨 위 빨간 상자에 서류에 비어 있는 항목이 나옵니다. 신청 정보(경력기간, 연료, 형태, 차량번호 등)는 이 화면에서, 기사 정보(주민번호, 면허, 차명 등)는 **기사 정보 수정하러 가기**로 채웁니다.
4. **서류 인쇄**: 저장 후 **서류 인쇄**(또는 **미리보기**). 4종을 A4로 한 번에 인쇄하며, 필요한 서류만 골라 인쇄할 수도 있습니다. 상태가 `작성` → `출력` 으로 바뀝니다. 서명·날인은 인쇄 후 직접 합니다.
5. **진행 관리**: **제출 완료** → 허가가 나면 **허가 처리**에 '배' 번호판 차량번호 입력 (기사 정보의 차량번호도 이 번호로 바뀜). 반려되면 **반려 처리**에 사유를 남기고, **다시 작성으로** 고쳐서 다시 인쇄합니다.

- 빈 항목이 있어도 확인 후 빈칸으로 인쇄할 수 있습니다 (손으로 채울 때).
- 인쇄할 때마다 그 내용이 암호화되어 신청서에 보관되고, `admin_log` 에 출력 기록이 남습니다.
- 서류 문구가 바뀌면 `src/Admin.html` 의 "배번호 서류 4종 인쇄 양식" 부분 글자만 고치면 됩니다.
- 휴대폰에서 인쇄가 안 되면 **미리보기**로 연 뒤 브라우저 메뉴의 인쇄(PDF 저장)를 쓰세요. 팝업이 막혀 있으면 허용해 주세요.

### 스케줄관리 (배차 · 2주 표)

기존 운영시트의 **스케쥴** 탭과 **백업** 탭을 합친 기능입니다.

스케줄 데이터는 기사·노선 DB 와 **따로**, 별도 파일 **`러너 올인원 스케줄 DB`** (`러너 올인원 데이터` 폴더) 의 `schedule` 탭에 저장됩니다. 스케줄관리를 처음 열 때 자동으로 만들어집니다 (기사 1줄 × 날짜 1칸, 올해 1월 1일 ~ 내년 12월 31일. 그 밖의 날짜로 가면 자동으로 늘어남).
- 예전 버전에서 `러너 올인원 DB` 안에 `schedule` 탭이 이미 있었다면, 처음 열 때 새 파일로 옮기고 원래 탭은 `schedule(이전됨)` 으로 이름만 바꿔 둡니다. 새 파일에 잘 들어간 것을 확인한 뒤 지워도 됩니다.
- 파일 ID 는 스크립트 속성 `SCH_DB_ID` 에 저장됩니다. 이 값을 지우면 다음에 스케줄관리를 열 때 빈 스케줄 DB 를 새로 만듭니다 (예: 해가 바뀌어 새 파일로 시작하고 싶을 때. 이전 파일은 드라이브에 그대로 남음).
- 스케줄 DB 파일에서 직접 고쳐도 바로 화면에 반영됩니다 (편집 트리거가 자동 설치됨).

**표 보기**
- 위쪽 **2주 / 한 달** 으로 보기를 바꿉니다 (마지막에 쓴 보기를 기억).
  - **2주**: 일요일부터 14칸. 앞 7일은 **확정 · 변경 불가**, 뒤 7일은 **예상 · 변동 있음**. **◀ 이전주 / 이번 주 / 다음주 ▶**
  - **한 달**: 기준을 고릅니다 — **달력 (1일~말일)** 또는 **정산 (전월 26일~당월 25일, 예: 11월분 = 10/26~11/25)**. **◀ 이전달 / 이번 달 / 다음달 ▶**. 매주 일요일 앞에 굵은 선. 출근일수·미입차·백업 명단·중복도 그 한 달 전체로 계산됩니다.
- 날짜마다 ISO 주차, 1~7일은 **Peak물량**, 공휴일 이름, 일·월요일은 **주말 수행률** 표시 (2주 보기).
- 날짜 칸으로 아무 날짜 검색 (한 달 보기에서는 그 날짜가 속한 달), 캠프·이름 검색.
- 줄 순서: 캠프 → 고정 → 품앗이 → 백업 → 외부용차 → 표 순서 → 이름. 승인된 기사만 나오고, **정지·대기 기사도 보기**를 켜면 나머지도 보입니다.
- 칸 색은 운영시트 드롭다운과 같습니다 (출근·휴무·병가·미입차·용차·노선변경). 업무등록은 민트, 다른 캠프 노선(예: `안양1 724ABCD`)은 노랑.

**입력**
- 칸을 누르고 바로 타이핑 (또는 두 번 클릭 / Enter). 아래에 추천 목록 (출근·휴무 등, 그 캠프 노선, 이번 2주에 쓴 값, 다른 캠프 노선). Enter 저장 후 아래 칸으로, Tab 오른쪽, Alt+Enter 줄바꿈, Esc 취소.
- 드래그 / Shift+클릭으로 여러 칸 선택 → Delete 지우기, **Ctrl+C / Ctrl+V 로 엑셀·구글시트와 그대로 주고받기** (한 칸을 복사해 여러 칸에 붙이면 모두 채움). Ctrl+Z 되돌리기.
- 고치면 1초 안에 자동 저장 (오른쪽 위 **모두 저장됨**). 다른 관리자가 먼저 바꾼 칸은 덮어쓰지 않고 최신 값으로 바꿔 알려 줍니다.
- 칸에 쓰는 글자는 운영시트와 같습니다: `출근`, `휴무`, `고정휴무`, `527B (D1,D2) [B01]`, `안양1 724ABCD`, `723D,116C (dasom1125) 업무등록` 등.
- **빈칸 자동 채우기**: 지금 보이는 기간(2주 또는 한 달)에서 고정·품앗이 기사의 오늘 이후 빈칸을 고정휴무 요일이면 `고정휴무`, 아니면 `출근`으로 (고정휴무일을 `목,금`처럼 요일로 적은 기사만).
- **+ 비고 줄**: 날짜별 메모 줄 추가. 줄 이름을 누르면 이름 바꾸기·삭제.
- 기사 이름을 누르면 **스케줄 설정**: 소속 캠프, 기본노선, 고정휴무일(요일 버튼), 추가휴무, 근무형태, 메모(서브 아이디 등), 표 순서.

**자동 계산 (운영시트 스크립트와 같은 규칙, 실제 운영시트 11/1~11/14 데이터로 결과가 같음을 확인)**
- **출근일수**: 빈칸·휴무·용차·병가·퇴사·미입차·업무등록·휴가를 뺀 칸 수.
- **미입차**: 기본노선이 있는데 그날 아무도 안 들어간 노선, 회전(D1·D2·F3) 일부만 찬 노선, `미입차`라고 적은 칸. 빨간 글씨.
- **백업 명단**: 백업·용차 기사의 칸에서 캠프별로 누가 어느 노선에 들어가는지.
- **중복**: 같은 날 같은 캠프·노선·회전에 두 명 이상 → 주황 테두리 + 중복 줄.
- 회전은 노선관리의 캠프 정보 **기본 회전**을 씁니다 (서초1처럼 D1,D2만 쓰는 캠프는 거기서 바꿈).

**기사 앱**: 홈의 **스케줄**을 누르면 기사님 본인의 이번 주(확정)·다음 주(예상) 일정이 보입니다 (읽기 전용).

### 노선관리 (캠프 > 노선코드)

노선관리 메뉴를 처음 열면 DB 시트에 `camps`(캠프), `routes`(노선), `camp_images`(캠프 참고 이미지), `camp_addresses`(상차지 주소), `route_prices`(구분별 단가) 탭이 **자동으로** 생깁니다. (setup 을 다시 실행하지 않아도 됩니다)

1. **캠프 추가**: 오른쪽 위 **+ 캠프 추가** → 캠프명, 캠프 주소, 메모. 캠프명은 겹칠 수 없습니다. 주소 옆 **지도**를 누르면 네이버 지도에서 열립니다.
   - **상차지가 캠프 주소와 다른 곳이면** 같은 창의 **+ 상차지 주소 추가**로 넣습니다. 여러 개 가능하고(최대 10개), 이름(상차지, 2상차지 등)도 바꿀 수 있습니다.
2. **노선 추가**: 캠프를 고르고 **+ 노선 추가** → 노선코드를 줄바꿈·쉼표·띄어쓰기로 여러 개 한꺼번에 붙여 넣을 수 있습니다. 저장 전에 어떻게 나뉘는지, 이미 있는 코드인지 미리 보여 줍니다.
3. **구분1~5는 노선코드에서 자동으로 나뉩니다.**
   - `110ABCD` → 구분1 `110` / 구분2 `A` / 구분3 `B` / 구분4 `C` / 구분5 `D` (앞쪽 숫자 = 구분1, 그 뒤 한 글자씩)
   - 한 구분이 두 글자 이상이면 `110-AB-C-D-E` 처럼 `-` 로 나눠 씁니다.
   - 영문은 자동으로 대문자, 띄어쓰기는 지워집니다. 같은 캠프 안에서는 같은 노선코드를 두 번 쓸 수 없습니다 (다른 캠프는 가능).
4. **노선 찾기·고르기**: 노선 표 위의 구분1~5, 사용여부 칸으로 거르고, 왼쪽 검색창에 노선코드를 넣으면 그 노선이 있는 캠프를 찾아 줍니다.
5. **노선 수정**: 노선 줄을 누르면 노선코드, 캠프(다른 캠프로 옮기기), 사용/중지, 메모를 고칠 수 있습니다. 체크박스로 여러 개를 골라 한꺼번에 사용·중지·삭제할 수도 있습니다. 당분간 안 쓰는 노선은 삭제보다 **중지**를 권장합니다 (나중에 배차·정산 기록이 남아 있어야 하므로).
6. **구분별 단가**: 노선 표 위의 **구분별 단가** 탭. 캠프 노선에서 숫자(구분1)별로 구분2~5의 글자가 자동으로 나열되고, 구분 옆에 **원청단가 · 기사단가 · 백업단가 · 품앗이단가 · 외부단가 · 일시단가(시작일~종료일)** 순서로 입력합니다.
   - 단가는 **숫자 + 구분 + 글자**마다 따로 정합니다. 예: `110ABCD` 는 110의 구분2 `A`, 구분3 `B`, 구분4 `C`, 구분5 `D` 단가를 씁니다. 110의 A 와 111의 A 는 따로입니다.
   - 위쪽에서 숫자·구분·글자로 거를 수 있습니다.
   - 칸을 여러 개 고친 뒤 **단가 저장**을 한 번 누르면 됩니다. Enter 를 누르면 아래 칸으로 넘어갑니다. 한 줄의 단가를 모두 지우고 저장하면 그 줄은 지워집니다.
   - 일시단가는 금액과 기간을 같이 넣어야 하고, 오늘이 기간 안이면 **일시 적용 중**으로 표시됩니다.
   - 노선을 누르면 수정 창에서 그 노선의 구분2~5 단가를 한눈에 볼 수 있습니다.
   - 단가 저장 기록은 `admin_log` 에 남습니다.
   - 실제 배차·정산에서 구분2~5 단가 중 어느 것을 쓸지(합산/가장 자세한 구분 등)는 배차·정산 단계에서 정합니다.
7. **참고 이미지**: **+ 이미지 추가** → 여러 장을 고르고 장마다 설명을 적어 올립니다. 사진은 자동으로 줄여서 올립니다. 이미지를 누르면 크게 보고, 설명 고치기, 순서 바꾸기(앞으로/뒤로), 삭제를 할 수 있습니다. 파일은 드라이브 `러너 올인원 데이터/캠프 참고 이미지` 폴더에 저장됩니다.
8. **캠프 삭제**는 그 캠프에 노선이 하나도 없을 때만 됩니다 (참고 이미지·상차지 주소·단가는 같이 지워짐).

### 데이터 초기화 (메뉴별)

기사 정보관리 · 스케줄관리 · 노선관리 · 업무스케줄 · 배번호 관리 화면 오른쪽 위의 **데이터 초기화** (빨간 글씨).

1. 누르면 무엇이 지워지는지 목록이 나옵니다.
2. 확인 칸에 **`모조리 없앤다`** 를 그대로 입력해야 **초기화** 버튼이 눌립니다 (서버에서도 한 번 더 확인).
3. 지우기 전에 해당 시트를 구글 드라이브 **`러너 올인원 데이터 / 초기화 백업`** 폴더에 새 파일로 복사해 둡니다. 완료 화면의 **초기화 백업 파일 열기** 로 바로 볼 수 있고, 잘못 지웠으면 그 파일에서 복사해 원래 시트에 붙여 넣으면 됩니다.
4. 누가 언제 무엇을 지웠는지 `admin_log` 에 백업 파일 주소와 함께 남습니다.

| 메뉴 | 지워지는 것 | 남는 것 |
| --- | --- | --- |
| 기사 정보관리 | 모든 기사, 기사 앱 로그인, 가입 서류 폴더(드라이브 휴지통) | 관리자 로그인, 스케줄·배번호 기록 |
| 스케줄관리 | 스케줄 DB 의 모든 날짜 기록, 비고 줄(빈 비고 줄 3개 다시 만듦) | 기사 정보, 기사별 스케줄 설정 |
| 노선관리 | 캠프·노선·상차지 주소·구분별 단가·참고 이미지(사진은 드라이브 휴지통), 기사의 소속캠프 칸 | 기사 정보, 스케줄 기록 |
| 업무스케줄 | 모든 메모 | — |
| 배번호 관리 | 모든 신청서 | 회사 정보 |

- 시트의 머리글(1행)·드롭다운·서식은 그대로 두고 데이터 줄만 비웁니다. 초기화 후 바로 새로 입력할 수 있습니다.
- 드라이브 휴지통으로 옮긴 파일은 30일 안에 드라이브에서 복구할 수 있습니다.

## 시트에서 직접 고치기

`러너 올인원 DB` 의 시트를 그대로 고치면 됩니다. 고치는 즉시 앱에 반영됩니다.

| 하고 싶은 일 | 시트에서 할 일 |
| --- | --- |
| 가입 승인 / 반려 / 사용 중지 | `drivers` 의 **상태** 칸을 `승인` · `반려` · `정지` 로 변경 (승인 시 승인일시 자동 기록) |
| 이름·주소·차량·은행 등 수정 | 해당 칸을 그냥 고침 |
| 주민등록번호 · 운전면허번호 · 계좌번호 수정 | 칸에 **새 번호를 그대로 입력** → 자동으로 암호화되고 `900101-1******` 처럼 가린 번호로 바뀜 (주민번호를 고치면 생년월일도 자동 갱신) |
| 기사 비밀번호 바꿔주기 | **비밀번호 재설정** 칸(주황색 머리글)에 임시 비밀번호 입력 → 바로 적용되고 칸은 비워짐. 기사는 다음 로그인 때 새 비밀번호를 직접 정함 (아래 참고) |
| 기사를 직접 등록 | 빈 줄에 이름(또는 쿠팡플렉스 아이디) 등을 입력 → 기사ID·가입일시·상태(승인대기) 자동 입력. 비밀번호는 위 방법으로 지정 |
| 기사구분·기사코드 | `drivers` 의 **기사구분**(고정/백업/품앗이/외부용차, `용차`·`고정기사` 처럼 써도 정리됨), **기사코드** 칸. 같은 기사코드가 있으면 칸에 메모로 알려 줌 |
| 특정 기기 강제 로그아웃 | `sessions` 시트의 **만료일시** 를 지금보다 이전 시각으로 변경 |
| 캠프 추가·이름 바꾸기 | `camps` 빈 줄에 캠프명 입력 → 캠프ID 자동. 캠프명을 바꾸면 `routes`·`camp_images` 의 캠프명 칸도 자동으로 바뀜 |
| 상차지 주소 추가 | `camp_addresses` 빈 줄에 캠프명, 이름(비우면 상차지), 주소 입력 |
| 구분별 단가 입력 | `route_prices` 빈 줄에 캠프명, 숫자(구분1, 예: `110`), 구분(`구분3` 또는 `3`), 글자(예: `B`), 단가들 입력 → 단가ID 자동. 금액은 `1,200원` 처럼 써도 숫자로 정리됨 |
| 스케줄 고치기 | **`러너 올인원 스케줄 DB`** 파일의 `schedule` 탭에서 기사 줄 × 날짜 칸을 그냥 고침 (1행 날짜와 A열 행ID는 바꾸지 말 것). 캠프·이름·기본노선 칸은 기사 정보를 따라 자동으로 맞춰짐 |
| 기사 스케줄 속성 | `drivers` 의 **소속캠프**(캠프명), **기본노선**, **고정휴무일**, **추가휴무**, **근무형태**, **스케줄 메모**, **스케줄 순서** 칸 |
| 노선 추가 | `routes` 빈 줄에 **캠프명**과 **노선코드**만 입력 → 노선ID·캠프ID·구분1~5·사용여부 자동 |
| 노선을 다른 캠프로 옮기기 | `routes` 의 **캠프명** 칸을 다른 캠프명으로 변경 |
| 노선 중지 | `routes` 의 **사용여부** 를 `중지` 로 (`x`, `N` 으로 써도 중지로 바뀜) |
| 캠프 참고 이미지 추가 | `camp_images` 빈 줄에 캠프명, 드라이브 이미지 **링크**, 설명 입력 |
| 내 메모 열 추가, 열 순서 바꾸기 | 자유롭게 가능. 앱은 열 위치가 아니라 **머리글 이름**으로 칸을 찾습니다 |

잘못된 값을 넣으면(예: 면허번호 자릿수 오류) 그 칸에 **메모(빨간 삼각형)** 로 이유가 표시되고 저장되지 않습니다.

### 지켜야 할 것 두 가지

1. **머리글(1행) 이름은 바꾸지 마세요.** 이름이 바뀌면 앱이 그 열을 찾지 못합니다. 실수로 바꿨다면 원래 이름으로 되돌리거나 `setup` 을 다시 실행하세요.
2. **숨겨진 열(…암호화, 해시, 솔트, 중복검사키)은 직접 고치지 마세요.** 이 칸들은 위의 보이는 칸을 고치면 자동으로 갱신됩니다.

### 개인정보 칸이 가려져 보이는 이유

주민등록번호는 법적으로 암호화해서 저장해야 하는 정보입니다(개인정보 보호법 제24조의2). 그래서 시트에는 가린 번호만 보이고, 고칠 때는 새 번호를 입력하면 자동 암호화되는 방식으로 만들었습니다. 원래 번호 전체는 배번호 신청서를 출력할 때 앱이 풀어서 사용합니다.

### 기존 기사 비밀번호 일괄 설정

1. `drivers` 시트에서 첫 기사 줄의 **비밀번호 재설정** 칸에 임시 비밀번호(영문+숫자 8자 이상, 예: `runner2026`)를 입력합니다.
2. 그 칸을 선택하고 칸 오른쪽 아래 작은 네모를 마지막 기사 줄까지 끌어내립니다. 한 번에 100줄 이하를 권장합니다.
3. 잠시 뒤 칸이 모두 비워지고 **비밀번호 변경 필요** 칸에 `Y` 가 채워지면 적용 완료입니다.
4. 기사님께 아이디와 임시 비밀번호를 알려 드립니다.
5. 기사님이 임시 비밀번호로 로그인하면 **새 비밀번호 설정 화면**이 먼저 나옵니다. 바꾸기 전에는 홈 화면으로 넘어가지 않습니다.
6. 기사님이 바꾸면 **비밀번호 변경 필요** 칸이 자동으로 비워집니다. 누가 아직 안 바꿨는지는 이 칸으로 확인합니다.

기사님이 스스로 비밀번호를 찾을 때는 **아이디, 이름, 연락처, 생년월일, 정산 계좌 은행, 계좌번호**가 모두 시트와 맞아야 합니다. 계좌 정보가 비어 있는 기사님은 스스로 찾을 수 없으니, 위 방법으로 관리자가 임시 비밀번호를 지정해 주세요.

임시 비밀번호는 여러 명이 같으므로, 바꾸기 전까지는 다른 사람이 로그인할 수 있습니다. 가능한 빨리 바꾸도록 안내해 주세요.

기사님은 언제든 앱 홈 화면 아래 **비밀번호 변경**에서 직접 바꿀 수 있습니다. 바꾸면 다른 기기의 자동 로그인은 해제됩니다.

### 기존 기사 서류 사진 한꺼번에 올리기

1. 구글 드라이브 `러너 올인원 데이터` → **`서류 올리기`** 폴더를 엽니다. (`러너 올인원 DB` 의 **서류 연결** 탭 B5 칸 링크로도 열 수 있습니다)
2. 서류 파일 이름을 **`기사_서류종류`** 로 바꿔서 이 폴더에 한꺼번에 끌어다 놓습니다.

   | 부분 | 쓸 수 있는 것 | 예 |
   | --- | --- | --- |
   | 기사 | 쿠팡플렉스 아이디 / 연락처 / 기사ID / 이름 (동명이인이 없을 때만) | `kim@flex.com`, `01012345678`, `김기사` |
   | 서류종류 | `자격증` / `면허증` / `사업자` / `자동차` (이 글자가 들어가면 됨) | `면허증`, `사업자등록증`, `자동차등록증` |

   예: `kim@flex.com_면허증.jpg`, `01012345678_자격증.png`, `김기사_사업자.pdf`
   이미지(jpg, png 등)와 PDF 를 올릴 수 있습니다.

3. `러너 올인원 DB` → **서류 연결** 탭 → **② 실행** 옆 체크박스를 누릅니다.
4. 끝나면 체크가 저절로 풀리고, **결과** 칸과 아래 기록표에 파일마다 연결/실패와 이유가 나옵니다.
   - 연결된 파일: 기사별 서류 폴더로 옮겨지고, `drivers` 시트의 서류 칸에 링크가 들어갑니다.
   - 실패한 파일: `서류 올리기` 폴더에 그대로 남습니다. 이름을 고친 뒤 다시 체크하면 됩니다.
   - 이미 서류 링크가 있던 기사는 새 파일 링크로 바뀌고, 예전 파일은 그 기사 폴더에 남습니다.

파일이 아주 많으면 한 번에 4분 30초까지만 처리하고 "한 번 더 체크해 주세요"라고 안내합니다. 다시 체크하면 남은 파일부터 이어서 처리합니다.

## 데이터 구조

- `drivers` 시트: 기사 1명 = 1줄. 날짜·시각은 모두 `2026-11-02 19:00:00` 형식의 글자로 저장되어 그대로 읽고 고칠 수 있습니다.
- `sessions` 시트: 로그인 기록. 매일 새벽 4시에 만료된 기록을 자동 정리합니다.
- `기사 서류` 폴더: 기사별 하위 폴더에 서류 사진 4장. `drivers` 의 `서류_…` 칸에 링크가 있습니다.
- `러너 올인원 스케줄 DB` 파일의 `schedule` 시트 (기사·노선 DB 와 별도 파일): 기사 1줄 × 날짜 1칸 (기존 운영시트 백업 탭과 같은 모양). A~E열 행ID·구분(기사/비고)·캠프·이름·기본노선, F열부터 날짜. 화면은 2주씩만 읽고 고친 칸만 씁니다.
- `camps` / `routes` / `camp_images` / `camp_addresses` / `route_prices` 시트: 캠프 1개·노선 1개·이미지 1장 = 1줄. 노선은 캠프ID로 캠프에 묶이고(캠프명 칸은 보기 편하라고 같이 적어 두는 사본), 구분1~5는 노선코드에서 자동으로 채워집니다.
- `캠프 참고 이미지` 폴더: 노선관리에서 올린 캠프 사진.

## 속도를 위해 적용한 것

| 방법 | 효과 |
| --- | --- |
| 시트 전체를 읽지 않고 TextFinder 로 해당 줄만 찾아 읽음 | 기사가 늘어나도 로그인 속도가 거의 그대로 |
| 머리글 위치, 아이디→줄 번호, 로그인 세션, 기사 요약을 캐시에 보관 | 자동 로그인 확인은 대부분 시트를 열지 않고 끝남 |
| 시트를 고치면 해당 캐시만 즉시 삭제 | 캐시를 써도 직접 수정이 바로 반영됨 |
| 서류 사진을 휴대폰에서 미리 압축(최대 1600px JPEG) 후 한 번에 전송 | 업로드 시간 대폭 단축 (원본 5MB → 약 300KB) |
| 중복검사·업로드는 잠금 밖, 최종 저장만 짧게 잠금 | 여러 명이 동시에 가입해도 대기 최소화 |
| 저장된 기사 정보로 홈을 먼저 보여주고 서버 확인은 뒤에서 | 자동 로그인 시 앱이 바로 열리는 체감 |
| 노선 기준 데이터(캠프·노선·이미지 목록)를 한 번에 읽어 캐시, 저장·시트 수정 때만 새로 읽음 | 노선관리 화면과 앞으로 만들 배차·정산 화면이 시트를 매번 열지 않음 |
| 노선 여러 개를 한 번의 쓰기로 추가, 캠프 사진은 동시에 3장씩 나눠 불러옴 | 노선 수백 개 입력, 사진 많은 캠프도 빠르게 표시 |

구글 Apps Script 특성상 서버 호출 1번에 보통 0.5~1.5초가 걸립니다. 위 방법은 호출 횟수와 호출당 작업량을 줄이는 것입니다.

## 보안

- 비밀번호: 솔트 + 비밀키(페퍼) + HMAC-SHA256 200회 반복 해시. 원문은 어디에도 남지 않습니다(재설정 칸도 적용 즉시 비움).
- 주민등록번호·운전면허번호·계좌번호: 암호화 후 무결성 태그까지 붙여 저장. 주민번호 중복 가입은 별도 검사키로 막습니다.
- 로그인 10회 실패 시 15분 잠금, 비밀번호 찾기 본인확인 5회 실패 시 30분 잠금.
- `러너 올인원 데이터` 폴더는 필요한 관리자에게만 공유하세요. 시트를 볼 수 있는 사람은 이름·연락처·주소를 볼 수 있습니다.
