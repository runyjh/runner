# 러너 올인원

택배 영업점 러너의 기사 관리·배차·정산 올인원 프로그램입니다.

| 무엇 | 어디에 |
| --- | --- |
| 프로그램 코드 (화면, 서버) | **이 GitHub 저장소** |
| 백엔드 데이터 (기사 정보, 로그인 기록) | 구글 드라이브의 `러너 올인원 DB` 시트 |
| 기사 서류 사진 | 구글 드라이브의 `기사 서류` 폴더 |
| 암호화 키 | Apps Script 스크립트 속성 (저장소에 없음) |

저장소의 `main` 브랜치에 코드가 올라오면 GitHub Actions가 **문법 검사 → Apps Script에 올리기 → 웹앱 새 버전 배포**를 자동으로 합니다. 기사용 앱 주소(URL)는 바뀌지 않습니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `src/Code.gs` | 서버 코드 (구글 시트·드라이브 입출력, 시트 직접 수정 처리, 암호화, 로그인) |
| `src/Index.html` | 기사용 화면 (로그인, 회원가입, 비밀번호 찾기) |
| `src/appsscript.json` | Apps Script 설정 (서울 시간대, 웹앱 공개 범위) |
| `scripts/check.js` | 배포 전 문법 검사 |
| `.github/workflows/deploy.yml` | 자동 배포 설정 |

## 처음 한 번만 하는 설정

### 1. Apps Script 프로젝트 만들기

1. 러너 업무용 구글 계정으로 [script.google.com](https://script.google.com) → **새 프로젝트** → 이름을 `러너 올인원`으로 바꿉니다. 코드는 붙여넣지 않습니다.
2. 왼쪽 **⚙ 프로젝트 설정** → **스크립트 ID**를 복사해 둡니다. → `SCRIPT_ID`
3. [script.google.com/home/usersettings](https://script.google.com/home/usersettings) 에서 **Google Apps Script API** 를 **사용**으로 바꿉니다. (자동 배포에 필요)

### 2. 자동 배포용 인증 정보 만들기

PC에 [Node.js](https://nodejs.org) (LTS)를 설치한 뒤, 터미널(윈도우는 명령 프롬프트)에서 실행합니다.

```
npx @google/clasp@2.4.2 login
```

브라우저가 열리면 1번과 **같은 구글 계정**으로 로그인하고 허용합니다. 그러면 아래 파일이 생깁니다.

- 윈도우: `C:\Users\사용자이름\.clasprc.json`
- 맥: `/Users/사용자이름/.clasprc.json`

이 파일을 메모장으로 열어 **내용 전체**를 복사해 둡니다. → `CLASPRC_JSON`
이 내용은 구글 계정 열쇠와 같으니 다른 곳에 붙여넣거나 공유하지 마세요.

> PC에 설치하기 어렵다면 GitHub 저장소의 **Code → Codespaces → Create codespace** 로 연 터미널에서
> `npx @google/clasp@2.4.2 login --no-localhost` 를 실행해도 됩니다.

### 3. GitHub Secrets 등록

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서 등록합니다.

| 이름 | 값 |
| --- | --- |
| `SCRIPT_ID` | 1번에서 복사한 스크립트 ID |
| `CLASPRC_JSON` | 2번에서 복사한 `.clasprc.json` 내용 전체 |
| `DEPLOYMENT_ID` | 6번에서 등록 (지금은 비워 둠) |

### 4. 첫 코드 올리기

저장소 **Actions → Apps Script 배포 → Run workflow** 를 누릅니다. 1~2분 뒤 초록색 체크가 뜨면 성공입니다. (DEPLOYMENT_ID 가 없다는 노란 경고는 정상입니다.)
Apps Script 편집기를 새로고침하면 `Code.gs`, `Index.html` 이 들어와 있습니다.

### 5. setup 실행 (DB 만들기)

1. 편집기에서 함수 선택 칸을 **`setup`** 으로 바꾸고 **▶ 실행**합니다.
2. **권한 검토** → 계정 선택 → "확인하지 않은 앱" 경고에서 **고급 → 러너 올인원(으)로 이동 → 허용**. 본인이 만든 스크립트라 나오는 정상 경고입니다.
3. 로그에 `설정 완료. DB: https://...` 가 나오면 드라이브에 `러너 올인원 데이터` 폴더, `러너 올인원 DB` 시트, `기사 서류` 폴더가 생긴 것입니다.

### 6. 웹앱 첫 배포

1. 편집기 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**
2. 다음 사용자 인증 정보로 실행: **나** / 액세스 권한: **모든 사용자** → **배포**
3. 나오는 **웹 앱 URL** 이 기사용 앱 주소입니다.
4. 같은 화면의 **배포 ID** 를 복사해 GitHub Secret `DEPLOYMENT_ID` 로 등록합니다.

이제부터는 코드가 바뀔 때마다 이 배포가 자동으로 새 버전이 됩니다.

## 코드를 고칠 때

1. GitHub에서 `src/` 의 파일을 고치고 `main` 에 커밋합니다. (웹에서 연필 아이콘으로 바로 고쳐도 됩니다)
2. **Actions** 탭에서 진행을 확인합니다. 문법 오류가 있으면 빨간 X 로 멈추고 배포하지 않습니다.
3. 초록 체크가 뜨면 기사용 앱에 반영된 것입니다. 휴대폰에서 새로고침해 확인하세요.
4. 릴리스 안내에 "setup 다시 실행"이 있으면 편집기에서 `setup` 을 한 번 실행합니다. 기존 데이터는 지워지지 않습니다.

**Apps Script 편집기에서 코드를 직접 고치지 마세요.** 다음 자동 배포 때 저장소 내용으로 덮어써집니다.

## 시트에서 직접 고치기

`러너 올인원 DB` 의 시트를 그대로 고치면 됩니다. 고치는 즉시 앱에 반영됩니다.

| 하고 싶은 일 | 시트에서 할 일 |
| --- | --- |
| 가입 승인 / 반려 / 사용 중지 | `drivers` 의 **상태** 칸을 `승인` · `반려` · `정지` 로 변경 (승인 시 승인일시 자동 기록) |
| 이름·주소·차량·은행 등 수정 | 해당 칸을 그냥 고침 |
| 주민등록번호 · 운전면허번호 · 계좌번호 수정 | 칸에 **새 번호를 그대로 입력** → 자동으로 암호화되고 `900101-1******` 처럼 가린 번호로 바뀜 (주민번호를 고치면 생년월일도 자동 갱신) |
| 기사 비밀번호 바꿔주기 | **비밀번호 재설정** 칸(주황색 머리글)에 새 비밀번호 입력 → 바로 적용되고 칸은 비워짐. 그 기사의 다른 기기 자동 로그인도 해제 |
| 기사를 직접 등록 | 빈 줄에 쿠팡플렉스 아이디·이름 등을 입력 → 기사ID·가입일시·상태(승인대기) 자동 입력. 비밀번호는 위 방법으로 지정 |
| 특정 기기 강제 로그아웃 | `sessions` 시트의 **만료일시** 를 지금보다 이전 시각으로 변경 |
| 내 메모 열 추가, 열 순서 바꾸기 | 자유롭게 가능. 앱은 열 위치가 아니라 **머리글 이름**으로 칸을 찾습니다 |

잘못된 값을 넣으면(예: 면허번호 자릿수 오류) 그 칸에 **메모(빨간 삼각형)** 로 이유가 표시되고 저장되지 않습니다.

### 지켜야 할 것 두 가지

1. **머리글(1행) 이름은 바꾸지 마세요.** 이름이 바뀌면 앱이 그 열을 찾지 못합니다. 실수로 바꿨다면 원래 이름으로 되돌리거나 `setup` 을 다시 실행하세요.
2. **숨겨진 열(…암호화, 해시, 솔트, 중복검사키)은 직접 고치지 마세요.** 이 칸들은 위의 보이는 칸을 고치면 자동으로 갱신됩니다.

### 개인정보 칸이 가려져 보이는 이유

주민등록번호는 법적으로 암호화해서 저장해야 하는 정보입니다(개인정보 보호법 제24조의2). 그래서 시트에는 가린 번호만 보이고, 고칠 때는 새 번호를 입력하면 자동 암호화되는 방식으로 만들었습니다. 원래 번호 전체는 배번호 신청서를 출력할 때 앱이 풀어서 사용합니다.

## 데이터 구조

- `drivers` 시트: 기사 1명 = 1줄. 날짜·시각은 모두 `2026-11-02 19:00:00` 형식의 글자로 저장되어 그대로 읽고 고칠 수 있습니다.
- `sessions` 시트: 로그인 기록. 매일 새벽 4시에 만료된 기록을 자동 정리합니다.
- `기사 서류` 폴더: 기사별 하위 폴더에 서류 사진 4장. `drivers` 의 `서류_…` 칸에 링크가 있습니다.

## 속도를 위해 적용한 것

| 방법 | 효과 |
| --- | --- |
| 시트 전체를 읽지 않고 TextFinder 로 해당 줄만 찾아 읽음 | 기사가 늘어나도 로그인 속도가 거의 그대로 |
| 머리글 위치, 아이디→줄 번호, 로그인 세션, 기사 요약을 캐시에 보관 | 자동 로그인 확인은 대부분 시트를 열지 않고 끝남 |
| 시트를 고치면 해당 캐시만 즉시 삭제 | 캐시를 써도 직접 수정이 바로 반영됨 |
| 서류 사진을 휴대폰에서 미리 압축(최대 1600px JPEG) 후 한 번에 전송 | 업로드 시간 대폭 단축 (원본 5MB → 약 300KB) |
| 중복검사·업로드는 잠금 밖, 최종 저장만 짧게 잠금 | 여러 명이 동시에 가입해도 대기 최소화 |
| 저장된 기사 정보로 홈을 먼저 보여주고 서버 확인은 뒤에서 | 자동 로그인 시 앱이 바로 열리는 체감 |

구글 Apps Script 특성상 서버 호출 1번에 보통 0.5~1.5초가 걸립니다. 위 방법은 호출 횟수와 호출당 작업량을 줄이는 것입니다.

## 보안

- 비밀번호: 솔트 + 비밀키(페퍼) + HMAC-SHA256 200회 반복 해시. 원문은 어디에도 남지 않습니다(재설정 칸도 적용 즉시 비움).
- 주민등록번호·운전면허번호·계좌번호: 암호화 후 무결성 태그까지 붙여 저장. 주민번호 중복 가입은 별도 검사키로 막습니다.
- 로그인 10회 실패 시 15분 잠금, 비밀번호 찾기 본인확인 5회 실패 시 30분 잠금.
- `러너 올인원 데이터` 폴더는 필요한 관리자에게만 공유하세요. 시트를 볼 수 있는 사람은 이름·연락처·주소를 볼 수 있습니다.
